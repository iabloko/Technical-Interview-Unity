# LINQ: отложенное выполнение и аллокации

LINQ — единый синтаксис запросов к коллекциям (`Where`, `Select`, `OrderBy`, `GroupBy`, `Aggregate`…). Работает поверх `IEnumerable<T>`.

## Отложенное выполнение (deferred execution)

Большинство операторов не выполняются в момент вызова — они строят цепочку итераторов. Реальный обход данных происходит при перечислении результата: `foreach`, `ToList()`, `ToArray()`, `Count()`, `First()`, `Sum()`.

```csharp
var query = items.Where(x => x.Active);   // ничего не вычислено
foreach (var x in query) { … }            // вычисление здесь
```

Последствия:
- **Повторное перечисление = повторное вычисление.** Каждый `foreach` по `query` заново прогоняет всю цепочку. Если источник изменился между перечислениями — результат другой. Нужен один снимок → материализовать через `ToList()`.
- **Захват переменных** в предикате подчиняется правилам [замыканий](delegates-events.md): актуальное значение берётся в момент перечисления.

Немедленные операторы (выполняются сразу): `ToList`, `ToArray`, `ToDictionary`, `Count`, `Sum`, `Min`, `Max`, `Average`, `Any`, `All`, `First`, `Single`.

## Аллокации

LINQ удобен, но в hot path дорог:
- Каждый оператор создаёт объект-итератор (аллокация в куче).
- Лямбды с захватом создают display-классы (аллокация).
- `ToList`/`ToArray` аллоцируют результирующую коллекцию.
- Перечисление идёт через `IEnumerator<T>` интерфейс → боксинг struct-энумераторов, виртуальные вызовы.

## Правило для Unity

В коде, выполняемом каждый кадр (`Update`, корутины, колбэки), **LINQ избегать** — это источник постоянных GC-аллокаций и спайков (см. [Unity GC](../03-unity-core/unity-gc.md)). Заменять на обычный `for`/`foreach` по конкретному типу.

LINQ уместен:
- В редакторных скриптах и инструментах (производительность некритична).
- В инициализации, загрузке, редком коде вне игрового цикла.
- Там, где читаемость важнее, а вызов разовый.

## Что спрашивают на собеседовании

- Что такое отложенное выполнение и чем оно опасно (повторное вычисление, изменившийся источник).
- Какие операторы выполняются немедленно.
- Почему LINQ не используют в hot path в Unity (аллокации, боксинг энумераторов).
- Разница между `First` и `FirstOrDefault`, `Single` и `First`.
