# Глоссарий (C#)

Краткие определения терминов, встречающихся в разделе C#.

### Мьютекс
**Mutex** (mutual exclusion — «взаимное исключение») — примитив синхронизации, который гарантирует, что в критическую секцию (к разделяемому ресурсу) в каждый момент времени имеет доступ только **один поток**. Поток захватывает мьютекс перед работой с ресурсом и освобождает после; остальные ждут освобождения.

В .NET: `System.Threading.Mutex` (может быть именованным и работать между процессами). Для синхронизации внутри одного процесса чаще применяют оператор `lock` (обёртка над `Monitor`).

```csharp
private static readonly object _gate = new object();

lock (_gate)            // одновременно в этой секции только один поток
{
    // доступ к разделяемому ресурсу
}
```

**Мьютексы доступны в Unity** — `System.Threading.Mutex` входит в стандартный .NET и работает как в Mono, так и в IL2CPP.

**Важно: Unity API не потокобезопасен.** Обращаться к `GameObject`, `Transform`, компонентам и прочему UnityEngine можно **только из главного потока** — даже под мьютексом. Синхронизировать имеет смысл лишь свои собственные данные между фоновыми потоками, а результат применять уже в главном потоке.

> На практике для блокировки внутри одного процесса предпочитают `lock` (легче и быстрее). `Mutex` нужен в основном для именованных / межпроцессных сценариев.

```csharp
private readonly Mutex _mutex = new Mutex();
private int _sharedScore;

void WorkerThread()                  // фоновый поток
{
    _mutex.WaitOne();                // захватываем мьютекс
    try { _sharedScore += 10; }      // безопасно меняем общие данные
    finally { _mutex.ReleaseMutex(); } // обязательно освобождаем
}
```
