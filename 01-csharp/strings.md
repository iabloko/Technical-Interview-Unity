# Строки: immutability, StringBuilder, interning

## Неизменяемость (immutability)

`string` — ссылочный тип, но **неизменяемый**. Любая «модификация» создаёт новую строку, исходная не меняется.

```csharp
s += "x";   // не дописывает в s, а создаёт новый объект и переназначает ссылку
```

Следствия:
- Конкатенация в цикле — квадратичная по аллокациям: каждая `+=` создаёт новую строку и копирует всё содержимое. N конкатенаций → O(N²) копирований и N промежуточных объектов в куче.
- Неизменяемость даёт потокобезопасность строк и возможность интернирования (см. ниже).

## StringBuilder

Изменяемый буфер символов. `Append`/`Insert`/`Clear` работают по месту, новая строка создаётся один раз — в `ToString()`.

```csharp
var sb = new StringBuilder();
for (int i = 0; i < n; i++) sb.Append(i).Append(',');
string result = sb.ToString();
```

Когда что:
- Несколько конкатенаций известной формы (`a + b + c`) — обычный `+` нормален (компилятор сворачивает в `string.Concat`).
- Конкатенация в цикле / неизвестное число фрагментов — `StringBuilder`.
- Задавать стартовую ёмкость `new StringBuilder(capacity)`, если размер примерно известен — меньше перевыделений внутреннего массива.

## Интернирование (string interning)

CLR хранит пул уникальных строк. **Строковые литералы** автоматически интернируются: одинаковые литералы в разных местах кода ссылаются на один объект.

```csharp
string a = "hi";
string b = "hi";
bool same = ReferenceEquals(a, b);   // true — один интернированный объект
```

- Строки, собранные в рантайме (конкатенация, ввод), **не** интернируются автоматически; `string.Intern(s)` помещает в пул вручную.
- Интернирование экономит память при множестве одинаковых строк, но пул живёт до конца процесса — не интернировать произвольные рантайм-строки (утечка).

## Специфика Unity

- Конкатенация/интерполяция/`string.Format` в `Update` — источник GC-аллокаций и спайков (см. [GC](../03-unity-core/unity-gc.md), [профилирование](../06-performance/profiling-methodology.md)).
- UI-текст обновлять через `TMP_Text.SetText(StringBuilder)` или `SetText` с форматом, не склеивая строки каждый кадр.
- Сравнение тегов — `CompareTag("Enemy")`, а не `tag == "Enemy"` (см. [conventions](../03-unity-core/conventions.md)).
- `ReadOnlySpan<char>` для парсинга без подстрок (см. [Span](span-memory.md)).
