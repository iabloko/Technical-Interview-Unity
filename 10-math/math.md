# Математика для геймплея: векторы, кватернионы, матрицы

## Векторы

`Vector3` — направление и/или точка. Базовое:

- **Длина** `magnitude` (= √(x²+y²+z²)); `sqrMagnitude` без корня — использовать для сравнения расстояний (дешевле).
- **Нормализация** `normalized` — вектор длины 1 (направление без масштаба).
- Сложение/вычитание: `B - A` — вектор из A в B.

### Скалярное произведение (dot)

`Vector3.Dot(a, b) = |a||b|cosθ`. Для **единичных** векторов = косинус угла между ними.

| Dot | Смысл (для нормализованных) |
|---|---|
| `1` | сонаправлены |
| `0` | перпендикулярны |
| `-1` | противоположны |
| `> 0` | угол острый (цель «впереди») |

Применение: «враг видит игрока» (`Vector3.Dot(forward, toTarget.normalized) > Mathf.Cos(fovDeg * 0.5f * Mathf.Deg2Rad)` — сравнение с косинусом **половины** угла обзора), проекция, освещение по Ламберту (`Dot(normal, lightDir)` — см. [lighting](../04-rendering/lighting.md)).

### Векторное произведение (cross)

`Vector3.Cross(a, b)` — вектор, **перпендикулярный** обоим, по правилу левой руки (Unity левосторонняя). Длина = площадь параллелограмма. Применение: нормаль к плоскости/треугольнику, определить поворот «влево/вправо» (знак Y у cross), построение базиса.

## Кватернионы

`Quaternion` представляет поворот в 3D. Используются вместо углов Эйлера, потому что:

- **Нет gimbal lock** (потери степени свободы при совпадении осей), в отличие от Euler.
- Корректная плавная интерполяция (`Slerp`).
- Композиция поворотов — умножением.

Правила:
- **Не складывать** кватернионы; комбинировать **умножением**: `qTotal = qB * qA` (сначала A, потом B). Порядок важен — умножение некоммутативно.
- Применить поворот к вектору: `q * v`.
- Создание: `Quaternion.Euler(x,y,z)`, `LookRotation(forward, up)`, `AngleAxis(angle, axis)`.
- Не править `.x/.y/.z/.w` руками — это не углы.

## Матрицы

`Matrix4x4` — аффинное преобразование (перенос + поворот + масштаб) в однородных координатах 4×4. В Unity обычно скрыты за `Transform`, но важны для понимания [графического конвейера](../04-rendering/graphics-pipeline.md): Model → View → Projection. `transform.localToWorldMatrix`, `Matrix4x4.TRS(pos, rot, scale)` — построение из компонентов. Порядок умножения матриц, как и кватернионов, некоммутативен.

## Интерполяция

- `Lerp(a, b, t)` — линейная интерполяция; `t` ограничивается диапазоном `[0,1]`. `LerpUnclamped` `t` не ограничивает и экстраполирует за пределы отрезка `a`–`b`.
- `Slerp` — сферическая (для направлений/кватернионов): равномерная угловая скорость, в отличие от `Lerp`.
- Частая ошибка: `Lerp(a, b, Time.deltaTime)` для «плавного следования» — это не линейное движение, а экспоненциальное приближение (framerate-зависимое); осознавать, что делаешь.

- Что показывает dot product и где применяется (угол, «впереди ли цель», освещение).
- Что даёт cross product (перпендикуляр, нормаль, сторона поворота).
